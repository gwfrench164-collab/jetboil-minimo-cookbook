# Your MiniMo cooking library

1. In this folder, double-click **Open Cookbook.html**. Your browser opens the library. No installation or internet connection is needed.
2. Search for a recipe, ingredient, cooking technique, or pantry item. Click a name to read it. Use the type menu to explore the whole library.
3. Tick the recipes you want. Click **My meals** to put them in order and add names such as “Friday dinner.”
4. Click **Create cookbook** or **Shopping list**. Use **Print / Save PDF** to print or save the result, or save it as text.

Use **Save meal plan** to keep your selections in a file. **Open saved meal plan** restores them later. Browser memory is convenient but may be cleared or unavailable for local files.

Each selected recipe contributes one batch. Quantities stay as recorded; the library does not yet scale portions or combine overlapping ingredients. You can select each recipe once per plan.

## What the labels mean

- **Source text checked · indexed copy:** compared with indexed official-page text; a fresh live-page check is still pending.
- **Source review pending:** the recipe has not yet been checked against its official source.
- **Project recipe · not official:** a recipe created for this project.
- **Reference record:** existing ingredient, technique, pantry or component information, without a new source audit.

MiniMo adaptations and untested variations appear separately from original directions. A source check is not a cooking test. Read the equipment and MiniMo notes before cooking.

The library preserves all 113 existing records. Some connections are incomplete or ambiguous; those are labeled instead of guessed. The database is the foundation, and your cookbook and shopping list are outputs made from it.

The older [four-breakfast cooking guide](output/pdf/MiniMo_Cooking_Guide.pdf) is also available. REI is a future source phase and has not been mixed into the official Jetboil collection.

## Find records that need attention

Use **Recipe source review** to distinguish live-page checks from indexed-copy checks. The header shows those counts separately; an indexed copy still needs a live comparison.

Use **Library connections** to find records with missing matches or multiple possible matches. Choose **Everything** under Type of information to review connections across ingredients, techniques and pantry modules as well as recipes. Each result shows its outgoing connection gaps. Open a record to inspect the original labels and possible targets. These filters help identify work; they do not select or certify a match automatically. Clear filters returns to all recipes.
