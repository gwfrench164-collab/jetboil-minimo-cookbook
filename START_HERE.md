# Start cooking here

Open [MiniMo Cooking Guide](output/pdf/MiniMo_Cooking_Guide.pdf).

This is your printable cooking guide. You can also open it on your phone or tablet.

- **Have a skillet and Pot Support?** Start with French Toast on page 2.
- **Using only the MiniMo pot?** Start with Quinoa Breakfast Bowl on page 4.
- Other choices: Breakfast Quesadilla on page 3 and Coffee Oatmeal on page 5.

Read the short stove and food-handling instructions on page 1 first. Then gather the ingredients on your chosen recipe page and follow its numbered steps.

You do not need to install anything or run any commands. The other folders are the working library used to maintain the cookbook.

This first guide contains four breakfasts. The rest of the cookbook is still being reviewed. The guide's practical adaptations are labeled and have not been field-tested.
